# Geometry 101 — ARC 3133

Open [GEOMETRY101-class-ready.blend](GEOMETRY101-class-ready.blend).

Use Blender's **Scene selector at the top right** to follow the lesson:

| Scene | What changes |
|---|---|
| 01 - Point | A parameter and an XYZ vector locate one point. |
| 02 - Line | Two points are connected as a curve. |
| 03 - Edge | The curve becomes a mesh edge: two vertices and one edge. |
| 04 - Face | Three corners form a triangle. |
| 05 - Solid | Four base corners and an apex form a closed pyramid. |
| 06 - Boolean | The pyramid is subtracted from a cube. |

**Width, Depth, and Height** are exposed in the GeometryNodes modifier in scenes 05 and 06. The two scenes use the same pyramid construction, with independent input values. The pyramid retains its original group name, `002-point in middle`.

Actual node names remain unchanged; explanations are in Frames. Press **Home** over the node editor to fit the graph, and **Ctrl+Space** to temporarily maximize an editor.

This is a geometry lesson in model units. It is not a prepared print file. Instructor notes and preparation history are kept in `reference/archive/geometry101-preparation/`, outside the generated course site.
