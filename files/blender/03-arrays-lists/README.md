# 03 · Arrays and Lists

Each teaching session has its own Blender file:

- [Arrays-Lists-Session-1.blend](Arrays-Lists-Session-1.blend) — Linear loop, Nested grid.
- [Arrays-Lists-Session-2.blend](Arrays-Lists-Session-2.blend) — Hexagonal array, Radial array, If and range, Sine curve.

Use the Scene selector in numbered order. Select the lesson object to see its Geometry Nodes. Change the exposed parameters in the modifier; press Home over the node editor to fit the graph.

| Scene | Exercise |
|---|---|
| 01 - Linear loop | COUNT, INDEX, REPEAT |
| 02 - Nested grid | NESTED GRID |
| 03 - Hexagonal array | HEXAGONAL ARRAY |
| 04 - Radial array | REPEAT AROUND A CIRCLE |
| 05 - If and range | IF THE INDEX IS IN THIS RANGE, MOVE IT |
| 06 - Sine curve | A FUNCTION CONTROLS THE CURVE |

Native node names are retained. Short explanations and things to try are in Frames. Save your own working copy.
