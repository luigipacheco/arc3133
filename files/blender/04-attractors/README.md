# 04 · Attractor

Open [Attractors.blend](Attractors.blend) in Blender 5.2.1 LTS or a compatible newer version.

Use the Scene selector in numbered order. Select the lesson object to see its Geometry Nodes. Change the exposed parameters in the modifier; press Home over the node editor to fit the graph.

| Scene | Exercise |
|---|---|
| 01 - Read the field | READ THE FIELD |
| 02 - One point | ONE POINT |
| 03 - Multiple points | MULTIPLE POINTS |
| 04 - Curve attractor | CURVE ATTRACTOR |

Native node names are retained. Short explanations and things to try are in Frames. Save your own working copy.

Paneling has two attractor assignments, with one sheet each: P3c presents a 3D field view and geometric response; P3d analyzes a Miami point cloud with supplied tools. This file demonstrates attractor methods. The Miami dataset and site-analysis package will be provided separately.
