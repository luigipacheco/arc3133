# 07 · Advanced Volumes

Each teaching session has its own Blender file:

- [Advanced-Volumes-Session-1.blend](Advanced-Volumes-Session-1.blend) — Mesh to SDF, Signed distance, SDF Boolean.
- [Advanced-Volumes-Session-2.blend](Advanced-Volumes-Session-2.blend) — Noise field.

Use the Scene selector in numbered order. Select the lesson object to see its Geometry Nodes. Change the exposed parameters in the modifier; press Home over the node editor to fit the graph.

| Scene | Exercise |
|---|---|
| 01 - Mesh to SDF | FROM A MESH BOUNDARY TO SIGNED DISTANCE |
| 02 - Signed distance | SIGNED DISTANCE |
| 03 - SDF Boolean | BOOLEAN OPERATIONS ON DISTANCE GRIDS |
| 04 - Noise field | NOISE FIELD |

Native node names are retained. Short explanations and things to try are in Frames. Save your own working copy.
