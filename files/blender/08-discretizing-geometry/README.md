# 08 · Discretizing Geometry

Each teaching session has its own Blender file:

- [Discretizing-Geometry-Session-1.blend](Discretizing-Geometry-Session-1.blend) — One contour, Contour stack.
- [Discretizing-Geometry-Session-2.blend](Discretizing-Geometry-Session-2.blend) — Section parts, Laid out parts.

Use the Scene selector in numbered order. Select the lesson object to see its Geometry Nodes. Change the exposed parameters in the modifier; press Home over the node editor to fit the graph.

| Scene | Exercise |
|---|---|
| 01 - One contour | A VOLUME MEETS ONE PLANE |
| 02 - Contour stack | CONTOUR STACK |
| 03 - Section parts | SECTION PARTS |
| 04 - Laid out parts | LAID OUT PARTS |

Native node names are retained. Short explanations and things to try are in Frames. Save your own working copy.
