**Issued Class 1 · Due Class 4 · Sep 15 · 5%**

A personal graphic system applied to every sheet in the course. Drawings, diagrams, renders, captions, typography and page layouts should work together rather than as separate decisions.

## Four pages. No more.

The constraint is the point: a graphic system you cannot state in four pages is not a system, it is a mood board.

| Page | Contains |
|---|---|
| 1 | Typography — typefaces and hierarchy, with sizes |
| 2 | Colour — palette with stated values; line weights with assigned uses |
| 3 | The 17" × 11" sheet template, with the grid shown explicitly |
| 4 | A sample sheet, using the system on real work |

## Requirements

- No more than 3 typefaces, with a hierarchy of 4+ levels
- 5+ colour palette with stated values and a written rationale
- 4+ defined line weights, each with an assigned use
- One tabloid template with the grid shown explicitly
- Built in a vector or layout editor, **not** a template-based tool

## Not permitted

Canva, Adobe Express, Figma templates, PowerPoint, Google Slides, Wix and similar drag-and-drop applications.

A template supplies the grid, the type hierarchy, the palette and the spacing — which is precisely the set of decisions this assignment asks you to make yourself.

Work in a vector or raster editor where you control the coordinate space directly: Illustrator, Photoshop and InDesign, or Inkscape, GIMP and Scribus. Affinity is also acceptable.

This is a provisional system. It is expected to change; a revision is submitted with the Final Booklet and assessed there.
