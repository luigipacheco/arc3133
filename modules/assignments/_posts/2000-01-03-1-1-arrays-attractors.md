**Due Class 6 · Sep 29 · 8%** · Module 1 — Fields

An array organizes points; an attractor differentiates them. This assignment explores what happens when the two are combined — a matrix of approaches in which different array types are driven by different attractor types, so that the same organizing structure yields very different fields depending on what varies across it.

## The matrix

| | Single point | Multiple points | Curve |
|---|---|---|---|
| **Linear** | | | |
| **Grid** | | | |
| **Hexagonal** | | | |
| **On curve** | | | |

**Pick three cells. Any three.** The comparison between them is the point.

## Requirements

- **3+** distinct array/attractor combinations, drawing on the array types covered in Tutorial 1.1
- All **three** attractor types across the set: single-point, multiple-point, curve
- **3+** distinct parameters driven by attractor distance — scale, rotation, density, height, colour
- **1+** composition containing 1,000 or more elements
- **1+** composition resolved spatially in 3D
- For one combination: **three views of the same system** — isometric, close-up, eye-level perspective
- Remap ranges documented on the sheet — input range in, output range out
- Minimum 2 sheets
- One precedent analysis — 2–3 sentences: what is the module, what generates the positions, what varies and what drives it

**Three different scales is not three parameters.** Rotation, density, height and colour are all sitting there unused.

## Prohibited

Array add-ons, scatter tools and preset falloff plugins. Arrays and falloff must be authored.

Submit a short written statement of your mechanism: how your falloff is computed, in your own words.

## Assessed on

Composition, density, rhythm, contrast, hierarchy, gradient, scale, depth and colour — and on whether the set reads as a **systematic exploration** rather than three unrelated images.
