Every tutorial is **pre-recorded and sent after the class before the one that uses it**. You are expected to have worked through it before the session.

Class time is then spent on:

1. **Questions and troubleshooting** — what did not work. Bring the file, not the description.
2. **Assignment briefing** — requirements and precedents.
3. **Supervised work and critique.**

This format only works if the tutorial is done beforehand. A session spent watching what you could have watched at home is a session not spent on your actual problem.

## Two versions of everything

Every tutorial is provided in **Grasshopper** and **Blender Geometry Nodes** versions, implementing the same logic in both.

Watch the one for your chosen environment. Skim the other at least once per module, to see the logic survive the change of interface.

## The tutorials

| **2.2** | 2D Fabrication | Class 6 | Laser cutting and CNC milling: kerf, tolerance, registration, nesting, labelling |
| **3.1** | Panelization + Tessellation | Class 8 | Building the component and the base mesh separately, then mapping one onto the other |
| **3.2** | Fabrication Strategies | Class 9 | Splitting a surface into printable parts, connections, orientation for a set, batching |

Tutorial 4.1 is the one point in the course where code is written rather than read. It is placed last deliberately, because reading comes first.
