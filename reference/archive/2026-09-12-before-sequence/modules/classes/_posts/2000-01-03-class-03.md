## What the machine does

A nozzle draws one flat layer, the bed drops, it draws the next.

- **It builds upward, never sideways.** Material can only be placed on material that is already there.
- **Layers are the weak direction.** A print snaps between layers long before it snaps across one.
- **Every decision is a time cost.** Finer layers, more material, more supports — all of it is hours on a shared machine.

## Manifold or it does not print

A model can look perfect on screen and be meaningless to a slicer.

| | |
|---|---|
| **Watertight** | No gaps. Every edge shared by exactly two faces. If water could leak out, it is not a solid. |
| **No self-intersection** | A shape that passes through itself has no unambiguous inside. |
| **Normals outward** | Every face has a front and a back. A flipped face tells the slicer that outside is inside. |

*A Boolean that left an open edge is the most common cause of a failed file.*

## Overhangs

Each layer needs something under it. How much is the whole question.

**The 45° rule** — beyond about 45° from vertical, a surface needs support, or a different orientation.

### The letter test

Four letters, four printing conditions. Find yours in your own model.

| Letter | Condition | Verdict | Why |
|---|---|---|---|
| **H** | Bridge | Prints fine | The crossbar spans between two legs that are already there. Anchored at both ends, so it can stretch across. |
| **V** | Slope | Fine to 45° | Each layer steps outward a little. Gentle is fine; past about 45° it droops. |
| **T** | Cantilever | Droops | The arms start in mid-air, anchored at one end only. Nothing to stretch to. |
| **i** | Island | Impossible | The dot begins with nothing underneath it at all. |

**A bridge is anchored at both ends. A cantilever is not. An island is anchored to nothing. That is the whole difference.**

*(after García Cuevas + Pugliese, "Advanced 3D Printing with Grasshopper")*

## Orientation is your only lever

Same geometry, two placements, very different prints. Rotating so a cantilevered arm rests on the bed removes the support, prints faster, gives a cleaner face — and is stronger, because the load is not across a layer line.

**No supports are permitted on the 0.1 print.** If it cannot print unsupported in any orientation, change the geometry. That is a legitimate and expected outcome.

## What the slicer does

1. **Cut into layers** — the solid is intersected by a stack of horizontal planes.
2. **Outline each layer** — each intersection becomes a closed curve, the perimeter.
3. **Fill the inside** — infill pattern and density, usually 10–20%.
4. **Order the moves** — perimeters, infill, travel, written out as G-code.

Sound familiar? Intersect a solid with a stack of planes, keep the profiles, order them. **That is Module 2** — and it is what a slicer has been doing all along.

## Four settings

| | | |
|---|---|---|
| **Layer height** | 0.2–0.3 mm | Finer looks better and takes proportionally longer. Draft is fine for 0.1. |
| **Infill** | 10–15% | Prints are hollow with a lattice inside. Solid is almost never needed. |
| **Walls / perimeters** | 2–3 | This, not infill, is what makes a print feel solid. |
| **Supports** | OFF | Not permitted for 0.1. Solve it with orientation. |

## Six ways it goes wrong

| Failure | Cause | Fix |
|---|---|---|
| **Warping** — corners lift off the bed | Cooling shrinkage beats bed adhesion | Clean bed, add a brim, keep drafts off it |
| **Elephant's foot** — bottom layers bulge | Nozzle too close, or bed too hot | Slicer setting, or chamfer the base yourself |
| **Stringing** — fine hairs between parts | The nozzle oozes while travelling | Retraction on. Fewer travel moves — ordering again |
| **Layer separation** — splits along a layer line | Weak bond, or load runs across layers | Reorient so stress runs along layers |
| **Droop** — an overhang sags | Nothing underneath to build on | Orientation. If that fails, change the geometry |
| **Spaghetti** — nozzle draws in mid-air | The part came off the bed part-way | Adhesion. Check the first layer before walking away |

## Print it or cut it

Printing is not the default. It is the expensive option.

| **Cut it** | **Print it** |
|---|---|
| Prismatic — one profile, extruded | Doubly curved — a vault, a shell |
| Flat, or made of flat pieces | Undercuts a blade cannot reach |
| Repeated many times | Detail in all three axes at once |
| Larger than your hand | Small and intricate |
| Site model massing: stacked chipboard | One-off with no flat description |
| *Minutes per sheet. Twenty buildings at once.* | *Hours per object. One at a time.* |

**The test:** can the object be described as a stack of flat profiles, or one profile extruded? Then cut it. A simple box printed is a box you waited six hours for.

## Your print — for 0.1

- **60 mm** maximum bounding box
- **No supports** — orientation is the only lever
- **Draft** layer height — this is a test, not a showpiece
- **One diagram** — chosen orientation, the overhangs it produces, why not the alternative
