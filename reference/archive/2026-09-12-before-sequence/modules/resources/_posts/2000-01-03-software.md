## Software

| Purpose | Environment | Notes |
|---|---|---|
| **Primary — graph environments** | Rhino + Grasshopper **or** Blender Geometry Nodes | Choose one. Blender is free and cross-platform |
| Reading and modifying code | Grasshopper Python / Blender Python | Runs inside the above; no separate install |
| Layout and post-processing | Illustrator, Photoshop, InDesign | Open-source equivalents accepted: Inkscape, GIMP, Scribus |
| Slicing | PrusaSlicer, Cura, or FabLab-specified slicer | Per FabLab standard |

**Template-based design tools are not permitted.** Canva, Adobe Express, Figma templates, PowerPoint, Google Slides and similar may not be used to produce any sheet, the Visual Identity Manual, or the Booklet.

The reason is the same one behind the prohibited-shortcuts list: a template supplies the grid, the type hierarchy, the palette and the spacing — which is precisely the set of decisions 0.2 asks you to make yourself.

## Materials

Consumables for the fabrication assignments are supplied by the School, subject to per-student limits.

| Module | Supplied | Allocation |
|---|---|---|
| 0 — first print | Filament | One print, 200 g |
| 1 — plotter demonstration | Paper and pens | 3 sheets, 1 pen |
| 2 — laser cutting | Chipboard, basswood or acrylic | 1 sheet |
| 3 — panel set | Filament | Per FabLab allocation |

Allocations are fixed. **Test cuts and failed prints count against the allocation**, so plan them deliberately rather than iteratively — this constraint is itself part of the fabrication lesson.

## Fabrication scope limits

| | |
|---|---|
| 0.1 first print | 60 mm bounding box · draft layer height · **no supports** |
| 2.2 assembly | 300 mm assembled bounding box · 1 sheet |
| 3.2 panel set | 300 mm assembled volume · print time per FabLab allocation |

Work exceeding these limits will not be scheduled on the machines.

## FabLab

The **FabLab Safety Orientation must be completed** to gain access to any part of the FabLab. Due by the end of Class 2. Without it you cannot use any machine, and you remain responsible for every fabrication deadline.
