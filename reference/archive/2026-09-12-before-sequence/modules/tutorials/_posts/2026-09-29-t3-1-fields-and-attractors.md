# Tutorial 3.1 — Fields and Attractors

| | |
|---|---|
| **Module** | 3 |
| **Released after** | Week 6 |
| **Reviewed** | Week 7 |
| **Feeds** | 3.1 Field + Plotter Drawing |

For every point: how far is it from something? Use that number to drive a property. That is the whole module.

## What it covers

- Measuring **distance** — to a point, to several points, to a curve
- Generating and reading the field **as a 2D image** before it drives anything
- `Map Range` as **remap**, with input and output ranges stated
- Falloff — linear, inverse, smooth, threshold — as a design decision, not a setting

Tested Blender Python scripts for this tutorial live in [`code/blender/`](https://github.com/luigipacheco/arc3133/tree/main/code/blender). Each has a `PARAMETERS` block at the top and `TRY IT` / `BREAK IT` sections at the bottom.
