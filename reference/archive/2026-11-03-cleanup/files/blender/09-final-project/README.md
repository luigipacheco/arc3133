# 09 · Final Project — Fabrication

Open [Final-Project-Fabrication.blend](Final-Project-Fabrication.blend) in Blender 5.2.1 LTS or a compatible newer version.

Use the Scene selector in numbered order. Select the lesson object to see its Geometry Nodes. Change the exposed parameters in the modifier; press Home over the node editor to fit the graph.

| Scene | Exercise |
|---|---|
| 01 - Print orientation | ORIENT THE MASSING STUDY FOR A SMALL PRINT |
| 02 - Fit coupon | TEST THE FIT BEFORE THE BATCH |
| 03 - Modular print | NINE RELATED PARTS — TEST ONE CONNECTION |
| 04 - Registered sections | REGISTERED SECTION ASSEMBLY |
| 05 - Cutting layout | CUTTING LAYOUT |
| 06 - Spacer rings | SPACERS PRESERVE THE SECTION INTERVAL |

Native node names are retained. Short explanations and things to try are in Frames. Save your own working copy.
