# Preparation archive

Historical backups, screenshots, inspection records, and incremental editing scripts from the Geometry 101 lesson's development. They were relocated together from the former project folder on September 12, 2026.

The current lesson is [GEOMETRY101-class-ready.blend](../../../files/blender/geometry101/GEOMETRY101-class-ready.blend); the current [teaching notes](../Geometry101-teaching-notes.txt) are outside this archive.

These scripts are records of edits to particular live Blender states. They are **not a rebuild pipeline or student teaching scripts**. Some retain the previous workspace path or expect an earlier scene/node arrangement. Do not run them against the current lesson without adapting them and inspecting the live file first.

`pyramid-sequence-verification.json` records the final six-stage checks and the exposed parameter tests. Earlier verification files describe superseded versions, including the removed sphere Boolean. The `.blend` backups preserve those earlier states.

This folder is under `reference/`, which the course's Jekyll configuration excludes from the generated site.
