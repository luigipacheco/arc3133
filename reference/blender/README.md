# Current Blender records

This folder contains the generated session manifest, current validation records, latest screenshot job status, and the repository organization record.

- Teaching files: `files/blender/`
- Screenshots: `images/blender/`
- Maintenance tools: `scripts/blender/`
- Preparation history and superseded files: `reference/archive/`

The session manifest is generated from `syllabus/course.yml`. Do not edit it separately. `sessions-verification.json` records evaluated results and file hashes; changed files need new verification before packaging.
